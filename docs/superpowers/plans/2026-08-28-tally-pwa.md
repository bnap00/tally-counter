# Tally PWA Implementation Plan

> Historical implementation plan, written 2026-08-28. Checkboxes describe the original plan, not the current release status.

**Goal:** Build a dependency-free, installable tally counter PWA with five counting modes, local persistence, accessible controls, optional device feedback, and complete offline operation.

**Architecture:** A pure ES module owns all state transitions and validation. A browser controller renders that state into one semantic page and coordinates optional Web APIs. A small service worker caches the static app shell.

**Tech Stack:** HTML5, CSS, vanilla JavaScript ES modules, Web App Manifest, Service Worker API, Node.js built-in test runner

---

## File map

- `counter.js`: versioned state schema, normalization, advance, undo, reset, target changes, and derived completion state.
- `counter.test.js`: unit tests for all state transitions and edge cases.
- `index.html`: counter surface, edge controls, reset confirmation, settings dialog, and metadata.
- `app.js`: storage, rendering, events, vibration, wake lock, theme, keyboard shortcuts, and service-worker registration.
- `style.css`: responsive full-screen layout, themes, safe areas, feedback motion, and accessibility states.
- `manifest.webmanifest`: PWA identity, display, colors, and icons.
- `service-worker.js`: static app-shell caching, offline navigation fallback, and cache upgrades.
- `icons/icon.svg`, `icons/icon-192.png`, `icons/icon-512.png`: neutral tally icons.
- `README.md`, `LICENSE`, `.gitignore`: concise public-repository documentation and metadata.

### Task 2: Mode transitions

**Files:**
- Modify: `counter.test.js`
- Modify: `counter.js`

- [ ] **Step 1: Add failing transition tests**

Cover endless increment, target stop, auto-reset hold and next-cycle behavior, countdown to zero, nested primary completion exactly once, nested secondary stop, step size, undo in every mode, reset, target 1, and `Number.MAX_SAFE_INTEGER`.

```js
test('holds auto-reset completion until the next advance', () => {
  let state = normalizeState({ mode: 'auto', counter: { value: 1, target: 2 } });
  state = advance(state);
  assert.equal(state.counter.value, 2);
  assert.equal(state.pendingReset, true);
  state = advance(state);
  assert.equal(state.counter.value, 1);
  assert.equal(state.pendingReset, false);
});

test('increments a nested cycle exactly once', () => {
  let state = normalizeState({
    mode: 'nested',
    counter: { value: 1, target: 2 },
    secondary: { value: 0, target: 2 }
  });
  state = advance(state);
  assert.equal(state.secondary.value, 1);
  state = advance(state);
  assert.equal(state.secondary.value, 1);
});
```

- [ ] **Step 2: Run tests and verify missing-export failures**

Run: `node --test counter.test.js`

Expected: FAIL for missing transition functions.

Every function returns normalized immutable state. Completion flags must be derived from the transition and never increment a nested cycle twice.
